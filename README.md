# EV 충전기 수요 예측 — LightGBM 파이프라인

EV 충전소의 **1시간 뒤 / 2시간 뒤 충전 비율**을 LightGBM으로 예측하는 AI 학습 파이프라인입니다.

---

## 프로젝트 구조

```
ev-charger-predict/
├── src/
│   ├── dataset.py      데이터 로드, 피처 엔지니어링, 시간 기반 split
│   ├── train.py        LightGBM 학습, 모델 저장/로드
│   ├── evaluate.py     메트릭 계산, 피처 중요도 플롯
│   └── predict.py      저장된 모델로 추론
├── outputs/
│   ├── models/         학습된 모델 (.pkl)
│   ├── plots/          피처 중요도 차트 (.png)
│   └── metrics/        평가 결과 (.csv)
├── data/processed/     입력 데이터 (git 제외)
├── config.py           모든 하이퍼파라미터 & 경로 중앙 관리
└── main.py             파이프라인 진입점
```

## 피처 목록 (18개)

| 구분 | 피처 |
|------|------|
| 상태 | `현재상태`, `1시간전` |
| 시간 | `hour`, `dayofweek`, `is_weekend`, `is_daytime` |
| 충전소 속성 | `충전기개수`, `충전기구분`, `유형`, `시도`, `시군구` |
| 환경 | `기온`, `강수량`, `공휴일` |
| 지역 통계 | `지역_전기차수`, `지역_충전기수`, `충전기당_경쟁률` |
| Target Encoding | `station_target_mean` (충전소별 평균), `station_hour_mean` (충전소×시간대 평균) |

> Target Encoding은 train set 기준으로만 계산하여 데이터 누수를 방지합니다.

## Split 전략

랜덤 split을 사용하지 않습니다. 미래 데이터 누수 방지를 위해 **시간 기반 split**을 적용합니다.

| 구간 | 기간 |
|------|------|
| Train | ~ 2025-01-24 23:00 |
| Validation | 2025-01-25 ~ 2025-01-27 23:00 |
| Test | 2025-01-28 ~ 2025-01-31 |

## 성능 결과

> **핵심 지표: rmse_nonzero** — 실제 충전 중인 시간대(non-zero)만 집계.  
> 전체 RMSE는 91.9%가 0인 분포 특성상 낮게 보이나 비즈니스 가치가 낮음.  
> "충전소가 바쁜 시간대를 얼마나 잘 예측하는가"가 실질 목표.

### v1.0 (단일 회귀)

| 지표 | 1시간뒤 | 2시간뒤 |
|------|---------|---------|
| RMSE (전체) | 0.1800 | — |
| R² | 0.1553 | 0.1205 |
| **rmse_nonzero** | **0.6212** | **0.6317** |

### v2.0 (2단계: 분류기 + 회귀기)

| 지표 | 1시간뒤 | 2시간뒤 |
|------|---------|---------|
| 분류기 AUC | 0.8424 | 0.8323 |
| **rmse_nonzero** | **0.4288 ▼31%** | **0.4259 ▼33%** |
| CLF_THRESHOLD | 0.08 | 0.08 |

**피처 중요도 Top 4 — 회귀기 (gain 기준)**

| 순위 | 피처 |
|------|------|
| 1 | station_hour_mean |
| 2 | 기온 |
| 3 | station_target_mean |
| 4 | 강수량 |

## 모델 구조 (v2.0)

```
입력 피처 (18개)
      │
      ▼
[Stage 1] LightGBM 분류기  →  P(충전 중)
      │
      ├── P < 0.08  →  예측값 = 0.0
      │
      └── P ≥ 0.08  →  [Stage 2] LightGBM 회귀기  →  충전 비율
```

Stage 2는 non-zero 행만으로 학습하여 실제 충전 중인 케이스의 비율 예측에 특화.
