# EV 충전기 수요 예측 — LightGBM 파이프라인

EV 충전소의 **1시간 뒤 / 2시간 뒤 충전 비율**을 LightGBM으로 예측하는 AI 학습 파이프라인입니다.

---

## 프로젝트 구조

```
ev-charger-predict/
├── src/
│   ├── dataset.py      데이터 로드, 피처 엔지니어링, 시간 기반 split
│   ├── train.py        LightGBM 학습, 모델 저장/로드
│   ├── evaluate.py     메트릭 계산, 피처 중요도 플롯
│   └── predict.py      저장된 모델로 추론
├── outputs/
│   ├── models/         학습된 모델 (.pkl)
│   ├── plots/          피처 중요도 차트 (.png)
│   └── metrics/        평가 결과 (.csv)
├── data/processed/     입력 데이터 (git 제외)
├── config.py           모든 하이퍼파라미터 & 경로 중앙 관리
└── main.py             파이프라인 진입점
```

## 데이터

| 항목 | 내용 |
|------|------|
| 파일 | `ratio_dataset_202501.csv` |
| 기간 | 2025-01-01 ~ 2025-01-31 |
| 크기 | 1,539,336행 × 17컬럼 |
| 충전소 수 | 2,069개 |
| 타겟 | `1시간뒤_정답(y)`, `2시간뒤_정답(y)` (충전 비율, 0~2) |
| 타겟 분포 | 0.0이 약 91.9% (대부분 미사용 상태) |

`data/processed/` 폴더에 CSV 파일을 넣어야 실행 가능합니다.

## 피처 목록 (18개)

| 구분 | 피처 |
|------|------|
| 상태 | `현재상태`, `1시간전` |
| 시간 | `hour`, `dayofweek`, `is_weekend`, `is_daytime` |
| 충전소 속성 | `충전기개수`, `충전기구분`, `유형`, `시도`, `시군구` |
| 환경 | `기온`, `강수량`, `공휴일` |
| 지역 통계 | `지역_전기차수`, `지역_충전기수`, `충전기당_경쟁률` |
| Target Encoding | `station_target_mean` (충전소별 평균), `station_hour_mean` (충전소×시간대 평균) |

> Target Encoding은 train set 기준으로만 계산하여 데이터 누수를 방지합니다.

---

## Split 전략

랜덤 split을 사용하지 않습니다. 미래 데이터 누수 방지를 위해 **시간 기반 split**을 적용합니다.

| 구간 | 기간 |
|------|------|
| Train | ~ 2025-01-24 23:00 |
| Validation | 2025-01-25 ~ 2025-01-27 23:00 |
| Test | 2025-01-28 ~ 2025-01-31 |

## v1.0 성능 결과

| 지표 | 1시간뒤 | 2시간뒤 |
|------|---------|---------|
| RMSE (전체) | 0.1800 | — |
| R² | 0.1553 | 0.1205 |
| RMSE (비영 구간) | 0.6212 | 0.6317 |

> **비영 구간 RMSE**: 실제 충전 중인 시간대(non-zero)만 집계한 핵심 지표.  
> 전체 RMSE는 91.9%가 0인 분포 특성으로 낮게 보이는 것에 주의.

**피처 중요도 Top 4 (gain 기준)**

| 순위 | 피처 |
|------|------|
| 1 | station_hour_mean |
| 2 | 기온 |
| 3 | station_target_mean |
| 4 | 강수량 |

## 다음 단계 (v2.0 계획)

목표 rmse_nonzero: **0.40 이하**
